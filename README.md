# ALFREDO GRE PORTAL

Free GRE practice that anyone can use in the browser. No account or sign-in needed.

**Live site:** https://alfredo.github.io/alfredo-gre-portal/

## Features

- **Today's 40** — a new 40-question mixed set every day.
- **Questions change every day** — Quant problems (including geometry figures and bar-chart data sets) and Verbal text completion / sentence equivalence questions (including harder two-blank contrasts) are generated fresh for each visitor each day.
- **14 reading passages and 8 short arguments** with 49 reading questions.
- **Full GRE test** — Analyze an Issue essay, Verbal 12 + 15, Quant 12 + 15, adaptive second sections, test-centre toolbar, calculator with Transfer Display.
- **Practice builder**, **marked results with explanations**, **error log**.
- **Study calendar** with auto-planning and calendar download (.ics).
- **Vocabulary** flashcards (140 words), **formula sheet**, **study planner**.

Progress is saved in each visitor's own browser, with backup and restore in Study Tools. The site can be installed to a phone's home screen and works offline once loaded.
